## 1. Action Verbs & Verification Standards

### Level 1: Remember
- **Verbs**: Recall, list, define, state, identify, name.
- **Verification**: Student correctly retrieves facts, formulas, or standard terms from memory without prompting.

### Level 2: Understand
- **Verbs**: Explain, summarize, paraphrase, classify, illustrate.
- **Verification**: Student restates the mechanics in their own words and interprets diagrams correctly.

### Level 3: Apply
- **Verbs**: Implement, calculate, execute, solve, demonstrate.
- **Verification**: Student produces functional code or solves quantitative problems in `exercises/`.

### Level 4: Analyze
- **Verbs**: Deconstruct, compare, contrast, debug, diagnose.
- **Verification**: Student identifies failure modes, traces edge cases, and explains why flawed alternatives fail.

### Level 5: Evaluate
- **Verbs**: Critique, defend, justify, assess, appraise.
- **Verification**: Student defends architectural trade-offs against adversarial personas and alternative paradigms.

### Level 6: Create
- **Verbs**: Design, construct, formulate, author, synthesize.
- **Verification**: Student develops an end-to-end capstone system in `projects/` solving an authentic domain challenge.
