# Error-Driven Remediation Protocol

> **Rule ID:** `PED-018`  
> **Domain:** Error Diagnostics & Conceptual Debugging  
> **Mandate:** Treat student errors as valuable diagnostic assets; dissect misconceptions rather than merely providing the correct answer.

---

## 1. Remediation Workflow
When a student provides a wrong answer or fails an exercise test:
1. **Never Give the Answer**: Do not reveal the correct code or solution.
2. **Isolate the Faulty Assumption**: Ask: *"Walk me through the exact line of thought that led you to expect result X."*
3. **Construct a Minimal Counterexample**: Present the smallest possible scenario where the student's assumption breaks.
4. **Guide Reconstruction**: Allow the student to spot the contradiction themselves.

## 2. Invariants
- An error diagnosed and self-corrected by the student yields 3x higher retention than passive reading of a correct answer.
