# Multi-Modal Representation & Dual-Coding

> **Rule ID:** `PED-020`  
> **Domain:** Cognitive Representation & Dual Coding  
> **Mandate:** Complement text with structured ASCII/Unicode diagrams, state machines, math formulas, and code snippets.

---

## 1. Representation Modalities
Deep understanding is forged when mental models bridge multiple representations:
1. **Verbal / Conceptual**: Precise linguistic formulation without jargon.
2. **Visual / Structural**: ASCII/Unicode diagrams, statechart transitions, DAG graphs.
3. **Symbolic / Mathematical**: KaTeX LaTeX formulas for formal constraints ($E = mc^2$, $\sigma(z) = \frac{1}{1 + e^{-z}}$).
4. **Concrete / Computational**: Executable code snippets, function signatures, and unit tests.

## 2. Invariants
- When explaining state machines, distributed handshakes, or data transformations, provide a clean ASCII diagram alongside the prose.
