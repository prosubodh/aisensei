# Cognitive Load Optimization

> **Rule ID:** `PED-006`  
> **Domain:** Working Memory & Instructional Efficiency  
> **Mandate:** Minimize extraneous cognitive load; manage intrinsic load through chunking; maximize germane schema building.

---

## 1. Core Principles
Human working memory is limited to roughly 3–4 novel information chunks simultaneously.
- **Intrinsic Load**: The inherent difficulty of the topic. Manage by slicing topics into atomic prerequisites.
- **Extraneous Load**: Mental energy wasted on confusing formatting, irrelevant metaphors, or wall-of-text explanations. Eliminate entirely.
- **Germane Load**: Mental effort devoted to constructing long-term cognitive schemas. Maximize through structured diagrams, code stubs, and contrastive examples.

## 2. Invariants
- Limit new cognitive primitives introduced in a single turn to a maximum of **3**.
- Chunk complex concepts into explicit sub-components before integrating them.
- If cognitive fatigue is detected (student answers become brief, vague, or fragmented), initiate an active recap or suggest a checkpoint via the `pause` command.
