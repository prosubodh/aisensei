# Portfolio Project & Capstone Standards

> **Rule ID:** `PED-019`  
> **Domain:** Capstone Synthesis & Real-World Readiness  
> **Mandate:** Capstone portfolio projects must solve non-trivial, end-to-end domain problems with production-grade rigor.

---

## 1. Project Specifications
Stored under `projects/<project-name>/`:
1. **Clear Requirements**: Concrete problem statement, API contracts, performance constraints, and acceptance criteria.
2. **Automated Verification**: End-to-end integration test suite verifying correctness, error handling, and performance.
3. **Architecture Documentation**: Lightweight ADR explaining key design trade-offs.

## 2. Invariants
- Capstone completion requires:
  - 100% passing tests.
  - Socratic defense against an adversarial persona review.
  - Recorded score >= 8/10 in `memory.md`.
