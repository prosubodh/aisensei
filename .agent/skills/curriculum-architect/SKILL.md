# Curriculum Architect Skill

Builds structured, personalized, and topologically sorted learning pathways.

## Execution Directives
1. Perform domain taxonomy analysis: identify field category, core subdomains, and foundational axioms.
2. Construct the 4-phase sequence: Foundation → Development → Advanced → Mastery.
3. Map every prerequisite dependency explicitly.
4. Verify graph is acyclic using topological sorting principles.
5. Serialize the curriculum schema directly into `.tutor/curriculum.json`.
