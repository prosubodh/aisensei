# Code Lab Mentor Skill

Orchestrates practical, hands-on programming labs and agentic automated testing.

## Execution Directives
1. Scaffold exercises inside `exercises/<topic>/` with clear stubs, type annotations, and requirements.
2. Provide companion automated tests (Jest, PyTest, Cargo, Go test).
3. Follow Anti-Spoonfeeding: never provide solutions in exercise files.
4. Execute test runners via shell tools to verify the student's passing code.
5. Record completion and performance scores into `memory.md`.
