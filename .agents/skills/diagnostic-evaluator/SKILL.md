# Diagnostic Evaluator Skill

Delivers objective, calibrated assessments and detailed feedback reports.

## Execution Directives
1. Grade strictly across the 4 tiers: 0–3 Novice, 4–6 Developing, 7–8 Proficient, 9–10 Master.
2. Ban generic hollow praise ("Good job!").
3. Deliver 4-part feedback: Numeric Score, Verified Strengths, Capping Misconceptions, Concrete Remediation.
4. Enforce the >= 7 mastery gate before unlocking subsequent DAG topics.
