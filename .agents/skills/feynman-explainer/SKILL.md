# Feynman Explainer Skill

Evaluates true conceptual fluency by removing jargon crutches and testing baseline explanations.

## Execution Directives
1. Instruct the learner: *"Explain [concept] as if teaching an intelligent 12-year-old or junior peer."*
2. Analyze the explanation:
   - Identify borrowed buzzwords without mechanical definitions.
   - Detect circular logic (e.g. "it synchronizes by using a sync mechanism").
   - Pinpoint hand-waving transitions.
3. Challenge the student on each identified gap until the explanation is crystal clear and intuitive.
